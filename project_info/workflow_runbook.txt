РУЧНОЕ ПОДТВЕРЖДЕНИЕ В GITHUB ACTIONS (CD)

Перейти в репозиторий на GitHub -> вкладка Actions.

Открыть текущий запуск воркфлоу.

Нажать Review deployments на шаге production.

Выбрать production и нажать Approve and deploy.
